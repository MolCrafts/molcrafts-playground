# MolCrafts Playground

Browser JupyterLab. The Python kernel is Pyodide.

Installed in this kernel:

- molpy, and the packages it depends on (molrs, mollog, molcfg, numpy)
- molvis

Not installed: molpack, molplot, molq. Those need a local Python environment.

Open `molpy-quickstart.ipynb` or `molvis.ipynb`.
